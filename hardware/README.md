# Phần cứng

Phần này bạn ĐTVT phụ trách. Sau khi chọn linh kiện thì điền `BOM.csv`, thêm `wiring.md` (sơ đồ nối dây, chân GPIO, mức logic, nguồn, dòng tải, mạch lái) và ảnh mạch đã lắp.

Bản MVP dùng micro của laptop. Micro I2S gắn trên board để giai đoạn sau. Gợi ý linh kiện giá rẻ có trong `docs/TASKS.md` (EE-01) và `docs/INTEGRATION.md`.
